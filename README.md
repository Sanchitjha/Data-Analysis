# Inventory & Sales Analytics Dashboard

End-to-end analysis of retail inventory and sales for a warehouse-style business: which items sell fast, which sit on the shelf,
and which need reordering now.

**Tools:** Python (Pandas) · PostgreSQL · Excel · Power BI (DAX)

## About the data
The data is **synthetic**, generated by `python/generate_data.py` (seeded, reproducible): 60 products in 5 categories,
2 years of daily sales (~61k order lines), restock history with supplier lead times, and current stock vs reorder level.
I simulated it because public sales datasets (e.g. Kaggle supermarket sales) contain no stock or restock data, which stock turnover
and reorder alerts need. The raw files are intentionally messy (duplicates, missing values, mixed date formats, prices stored as `$12.50` text)
so the cleaning step is real. To use a Kaggle dataset instead, drop it into `data/raw` and adapt the notebook.

## Pipeline
| Step | File | What it does |
|---|---|---|
| 1 | `python/generate_data.py` | Creates `data/raw/*.csv` |
| 2 | `python/01_cleaning_and_eda.ipynb` | Cleans with Pandas → `data/clean/*.csv`, EDA, pandas KPI cross-check |
| 3 | `sql/01_schema.sql`, `02_load_data.sql`, `03_analysis_queries.sql` | PostgreSQL schema, load, KPI queries |
| 4 | `powerbi/` | Model tables, DAX measures (`measures.dax`), build steps (`BUILD_GUIDE.md`) |
| 5 | `excel/Inventory_Sales_Summary.xlsx` | Data table + SUMIFS summaries, monthly chart, reorder flags |
| – | `python/dashboard_preview.py` | Matplotlib mock-up of the dashboard layout (`screenshots/`) |

## Cleaning decisions
- 724 duplicate order lines removed (kept the most complete row per `order_id`)
- 3 date formats parsed to one; `$` stripped from prices
- 597 missing unit prices filled from the product master; missing store → `Unknown`
- 356 rows with missing quantity dropped (cannot be inferred; <1% of rows)
- Category names standardised (case / whitespace)

## KPI definitions
- **Stock turnover** = units sold ÷ average stock, average stock = (opening stock + current stock) ÷ 2 → how many times stock was sold and replenished
- **Days of inventory** = days in period ÷ turnover
- **Fast / slow movers** = top / bottom quartile of turnover
- **Reorder alert** = `current_stock <= reorder_level`; also shows days of stock left at the last-90-day sales rate

## Key results (from the data)
- Total sales **$1.79M**, 111.7k units, gross margin ≈ 30%
- Beverages are the largest category (30% of revenue) with a clear summer peak; sales dip each Q4
- Turnover ranges from ~5× (Green Tea, Toothpaste, Mouthwash) to ~52× (Namkeen Mix): slow movers are overstocked, fast movers run out
- **17 of 60 items are at/below reorder level**; 7 are at zero stock (e.g. Sugar, Sunflower Oil, Lemonade)

## Reproduce
```bash
pip install pandas numpy matplotlib openpyxl nbformat nbconvert ipykernel
python python/generate_data.py
jupyter nbconvert --to notebook --execute --inplace python/01_cleaning_and_eda.ipynb
createdb inventory
psql -d inventory -f sql/01_schema.sql -f sql/02_load_data.sql   # run from repo root
psql -d inventory -f sql/03_analysis_queries.sql
python python/build_excel_and_exports.py
python python/dashboard_preview.py
```
